A travel poster for **LUMARIS**, a place that does not exist: a floating island
in a violet dusk sky pours a waterfall of golden light into a calm turquoise
lagoon, with one tiny white sailboat on the water for scale. Classic
mid-century travel-poster style, deep teal and gold palette, the place name
set large and legible across the lower third — and no other copy.

Entry for the make.fun bounty
[The Poster for a Place That Isn't There](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539).

## How it works

`main.ts` (Node 22, standard library only, no network) copies
`assets/poster.png` to `/output/entry.png` and verifies the result is a whole
PNG of at most 1,048,576 bytes.

```sh
node main.ts
```

## Files

- `main.ts` — the entry program
- `assets/poster.png` — the poster (1024×1024 PNG, 526,902 bytes)
